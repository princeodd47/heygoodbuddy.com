# Lufia II capsule monsters research

Working notes behind `docs/games/lufia-ii/capsule-monsters.md`. This folder is outside `docs/`,
so it never gets published to the site.

Everything below is our own summary. Don't copy from sources.

**How to use:** full-game page; the user has given no progress for this
game, so nothing is held back. If the user reports something different
in-game, the in-game value wins. Fix the page and these notes.

## Sources (researched 2026-10-26)

- RPGClassics Lufia 2 shrine, http://www.rpgclassics.com/shrines/snes/lufia2/ (Rast's capsule monster list): forms, master-form fruit, locations.
- Iron Knuckle (Telago) GameFAQs walkthrough v5.5, faqs/11045, Appendix A: elements, behavior, fruit drop sources, feeding tips
  (SELECT shows request, doubled value, reset trick, appetite).
- c0i9z, Capsule Monsters Item Tier Guide, GameFAQs faqs/81897: item tiers
  0 to 4 for feeding. Tier 0 consumables and cheap gear, tier 1 early gear
  and Secret Fruit and Hi Magic, tier 2 Parcelyte to Bound gear and Miracle,
  tier 3 rocks, jewels and S-rings, tier 4 endgame and Ancient Cave gear.
