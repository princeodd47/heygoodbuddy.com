# Lufia II magic research

Working notes behind `docs/games/lufia-ii/magic.md`. This folder is outside `docs/`,
so it never gets published to the site.

Everything below is our own summary. Don't copy from sources.

**How to use:** full-game page; the user has given no progress for this
game, so nothing is held back. If the user reports something different
in-game, the in-game value wins. Fix the page and these notes.

Data lives in `data/lufia-ii/magic.yaml`.

## Sources (researched 2026-11-17)

- RPGClassics Lufia 2 shrine, https://shrines.rpgclassics.com/snes/lufia2/spells.shtml:
  name, MP, price, who can learn it, shops, effect.
- Almar's Guides spell list,
  https://www.almarsguides.com/retro/walkthroughs/snes/games/lufiaii/misc/lists/spells/:
  each spell's element.

## Open questions

- Fireball's MP: RPGClassics shows "g" (a typo). The page says "Check in
  game: MP cost".
- Flash: RPGClassics calls it an electric shock and Almar's lists it as
  thunder; the Light Jewel's IP of the same name is light.
