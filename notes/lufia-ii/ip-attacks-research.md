# Lufia II IP attacks research

Working notes behind `docs/games/lufia-ii/ip-attacks.md`. This folder is outside `docs/`,
so it never gets published to the site.

Everything below is our own summary. Don't copy from sources.

**How to use:** full-game page; the user has given no progress for this
game, so nothing is held back. If the user reports something different
in-game, the in-game value wins. Fix the page and these notes.

Data lives in `data/lufia-ii/ip.yaml` (effects, groups). The gear for each
IP comes from the `ip` field in `data/lufia-ii/equipment.yaml`, so names
match the Equipment page; `gear` in ip.yaml covers only Crisis Cure (Holy
Robe) and Do-re-mi (Song Rock), whose gear isn't in equipment.yaml.

## Sources (researched 2026-11-17)

- RPGClassics Lufia 2 shrine, https://shrines.rpgclassics.com/snes/lufia2/ip.shtml:
  every IP, its gear and effect.
- Almar's Guides IP list,
  https://www.almarsguides.com/retro/walkthroughs/snes/games/lufiaii/misc/lists/iptechniques/:
  cross-check of effects.
