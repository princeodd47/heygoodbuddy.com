# Lufia II bestiary research

Working notes behind `docs/games/lufia-ii/bestiary.md`. This folder is outside `docs/`,
so it never gets published to the site.

Everything below is our own summary. Don't copy from sources.

**How to use:** full-game page; the user has given no progress for this
game, so nothing is held back. If the user reports something different
in-game, the in-game value wins. Fix the page and these notes.

Data lives in `data/lufia-ii/bestiary.yaml` (built with a one-off script
from Telago's monster appendix and RPGClassics' monster pages).

## Sources (researched 2026-10-26)

- Iron Knuckle (Telago) GameFAQs walkthrough v5.5, faqs/11045: level, HP, EXP, gold, drop item and percent, weak/strong.
- RPGClassics Lufia 2 shrine, http://www.rpgclassics.com/shrines/snes/lufia2/: which monsters appear in each area.
