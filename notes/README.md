# Research notes

One notes file per researched site page: `notes/<game>/<page>-research.md`.
This folder is outside `docs/`, so it never gets published.

Each file records what the page and its YAML don't:

- **Sources:** where the information came from, and when.
- **Open questions:** conflicts between sources, and things to check in-game.
  What the player sees in-game always wins.
- **Held back:** content past the player's progress, sorted by when it
  becomes available, ready to move onto the page.
- **Already on the page:** a short list, so nothing gets researched twice.

Write in our own words; don't copy text from wikis or transcripts.
