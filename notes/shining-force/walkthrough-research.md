# Shining Force walkthrough research

Working notes behind `docs/games/shining-force/walkthrough.md`. This folder is outside `docs/`,
so it never gets published to the site.

Everything below is our own summary. Don't copy from sources.

**How to use:** full-game page; the user has given no progress for this
game, so nothing is held back. If the user reports something different
in-game, the in-game value wins. Fix the page and these notes.

## Open questions

- Defeat rule (keep EXP, lose half gold, return to the last priest) is
  general series knowledge, not from these guides.
- Musashi: DV says a sign on the house with two doors north of the castle;
  DvD says the sign under the "Tales of Really Long Ago" bookshelf after
  talking to the king again. Page combines both.
- Pao Bronze Lance price: DV walkthrough box vs Dinob0t (300). Not on page.
