# Shining Force bestiary research

Working notes behind `docs/games/shining-force/bestiary.md`. This folder is outside `docs/`,
so it never gets published to the site.

Everything below is our own summary. Don't copy from sources.

**How to use:** full-game page; the user has given no progress for this
game, so nothing is held back. If the user reports something different
in-game, the in-game value wins. Fix the page and these notes.

Data lives in `data/shining-force/bestiary.yaml`, built by a one-off
script from DV's enemy listing and battle rosters.

## Sources (researched 2026-10-26)

- Dark_Vortex (Quan Jin), Shining Force Guide and Walkthrough v1.0, GameFAQs genesis faqs/51880: enemy listing (HP, ATT, DEF, AGI, MOV, weapon, spells) and each
  battle's roster and win condition.

## Open questions

- DV lists stats per enemy type, not per battle; some enemies may differ
  between battles. "Skeleton (stronger)" is DV's Skeleton V2 in Battle 16.
- Enemy "weapon" entries like Shield Ring are their equipment; only the
  Heat Axe, Doom Blade and Demon Rod are confirmed as obtainable.
