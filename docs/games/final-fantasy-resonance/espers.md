# Espers

Espers are summons. Only **Fina** can call them.

## Summoning

- A summon costs **50 MP**.
- The Esper opens with its **signature move**, then stays for **3 turns**.
  On those turns it picks its own moves, in no set order.
- While it's out, it has **Break the Limit**, which raises the damage cap to
  99,999.
- To get an Esper, you beat it in a fight first. Each one drops a **Magicite
  Shard** when you win.
