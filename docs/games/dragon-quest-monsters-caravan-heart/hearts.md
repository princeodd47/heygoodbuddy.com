# Hearts & Reforming

## Reforming

**Base monster + heart + heart = new monster.**

### Dragon Lord

1. Any monster + Pural + Pural = **Pural**
2. Pural + Dark Spirit + Rain Hawk = **Dark Spirit**
3. Dark Spirit + Scarabator + Roboster 2 = **Durran**
4. Durran + Chaos Drake + Divinegon = **Dragon Lord**

### Gisvarg

=== "From Iiro"

    1. Any monster + Iiro + Iiro = **Iiro**
    2. Iiro + Earth Spirit + King Leo = **Earth Spirit**
    3. Earth Spirit + Muscle Kong + Night Lich = **Barbaru**
    4. Barbaru + Gryphynx + Durran = **Domedy**
    5. Domedy + DrakMachine + Warubou = **Gisvarg**

=== "From Dreen"

    1. Dreen + Wind Spirit + Cergainas = **Wind Spirit**
    2. Wind Spirit + Giga Draco + Gran Satan = **Barbaru**
    3. Barbaru + Gryphynx + Durran = **Domedy**
    4. Domedy + DrakMachine + Warubou = **Gisvarg**

### Master Dragon

1. Any monster + Pural + Pural = **Pural**
2. Pural + Dark Spirit + Rain Hawk = **Dark Spirit**
3. Dark Spirit + Light Spirit + Gold Slime = **Light Spirit**
4. Light Spirit + Celestial Beast + Watabou = **Celestial Beast**
5. Celestial Beast (+99) + Master Dragon + Gisvarg = **Master Dragon**
